## Metode dan cakupan

Akun sementara dibuat sebagai fixture; penugasan, login, navigasi, pengisian assessment dan penerbitan sertifikat pada alur terpadu dilakukan melalui Chromium di alamat HTTPS publik. Uji batas nilai menggunakan akun uji dan pengaturan nilai fixture untuk menguji kondisi 69/70 secara tepat. Pemeriksaan API melengkapi alur browser untuk respons gagal dan kontrol akses. Tidak ada error JavaScript pada alur browser terpadu.

Pengujian mobile memakai viewport Chromium 390px, bukan perangkat fisik. Ini pengujian fungsional, bukan uji beban atau ketahanan layanan saat komputer lokal/tunnel mati.

## Temuan saat pengujian

Skrip awal belum menunggu konten SCORM dan form assessment selesai dirender. Penantian diperbaiki dan skenario dijalankan kembali hingga lulus. Tidak ada perubahan kode aplikasi yang diperlukan pada sesi pengujian ini.

## Pembersihan

Akun, enrollment, progres, attempt, sertifikat, SkillHub sementara serta audit log terkait uji dibersihkan. Pemeriksaan akhir: **0 akun uji tersisa** pada cakupan run ini. Materi dan riwayat peserta yang sudah ada tidak diubah. Sertifikat uji tidak dipertahankan sebagai sertifikat aktif.
